Getting Started Guide

The most important setup paths are pipeline creation, Google Workspace connection, and Telegram bot token verification.

1. Create a Pipeline Task

Click any screenshot to open it full size.

  1. Click Add New Feature / Task from the dashboard.
  2. Choose Pipeline Task.
  3. Use AI Auto-Configure for a guided setup, or switch to manual setup.
  4. Select an AI agent and model, add a web or YouTube source, choose a delivery target, and set a schedule time.
  5. Save the task. Use Start for scheduled runs or Run Now for a manual test.

2. Connect Google Workspace

Click any screenshot to open it full size.

  1. Open Settings and click Connect Google.
  2. Follow the step-by-step Google Cloud guide shown in the app.
  3. Create or select a Google Cloud project, enable the required Docs and Sheets APIs, and create a Desktop OAuth client.
  4. Select the downloaded OAuth JSON in TaskPilotSignal and complete the Google account authorization.
  5. After connection succeeds, pipeline delivery can write to the Docs or Sheets URLs you provide.

3. Get a Telegram Bot Token

Click the screenshot to open it full size.

  1. Open Telegram and search for @BotFather.
  2. Send /newbot and follow BotFather's prompts.
  3. Copy the generated bot token.
  4. Open a 1:1 chat with your new bot and send /start or any message once.
  5. In TaskPilotSignal, open Settings > Telegram Bot Tokens, add the token, and verify it. Chat ID is detected automatically.

Telegram Bot Commands

  • /help - show available commands.
  • /ping - check whether the bot is alive.
  • /change ai gemini - switch the active AI provider.
  • /newsession - start a fresh AI conversation.
  • /resume - continue the saved session where available.

시작 가이드

가장 중요한 설정은 작업 파이프라인 생성, Google Workspace 연결, 텔레그램 봇 토큰 검증입니다.

1. 작업 파이프라인 만들기

스크린샷을 누르면 원본 크기로 볼 수 있습니다.

  1. 대시보드에서 새로운 기능/작업 추가를 누릅니다.
  2. 파이프라인 작업을 선택합니다.
  3. 처음에는 AI 자동 설정으로 안내를 받거나, 직접 구성하려면 수동 설정으로 전환합니다.
  4. AI 에이전트와 모델, 웹 또는 YouTube 소스, 전달 대상, 실행 시간을 설정합니다.
  5. 작업을 저장한 뒤 시작으로 예약 실행하거나 즉시 실행으로 테스트합니다.

2. Google Workspace 연결

스크린샷을 누르면 원본 크기로 볼 수 있습니다.

  1. 설정에서 Google 연결을 누릅니다.
  2. 앱에 표시되는 단계별 Google Cloud 가이드를 따릅니다.
  3. Google Cloud 프로젝트를 만들거나 선택하고, Docs/Sheets API를 활성화한 뒤 Desktop OAuth 클라이언트를 만듭니다.
  4. 다운로드한 OAuth JSON 파일을 TaskPilotSignal에서 선택하고 Google 계정 권한 승인을 완료합니다.
  5. 연결이 완료되면 파이프라인 결과를 사용자가 입력한 Google Docs 또는 Sheets URL로 전달할 수 있습니다.

3. 텔레그램 봇 토큰 얻기

스크린샷을 누르면 원본 크기로 볼 수 있습니다.

  1. Telegram에서 @BotFather를 검색합니다.
  2. /newbot을 보내고 BotFather의 안내를 따릅니다.
  3. 생성된 봇 토큰을 복사합니다.
  4. 새 봇과 1:1 채팅을 열고 /start 또는 아무 메시지를 한 번 보냅니다.
  5. TaskPilotSignal의 설정 > 텔레그램 봇 토큰에서 토큰을 추가하고 검증합니다. 채팅 ID는 자동으로 감지됩니다.

텔레그램 봇 명령어

  • /help - 사용할 수 있는 명령어를 확인합니다.
  • /ping - 봇이 정상 작동 중인지 확인합니다.
  • /change ai gemini - 사용할 AI 제공자를 변경합니다.
  • /newsession - 새 AI 대화를 시작합니다.
  • /resume - 가능한 경우 저장된 세션을 이어갑니다.
