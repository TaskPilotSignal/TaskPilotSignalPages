How it works

The app keeps the setup local and walks you from source selection to delivery.

1

Choose a source

Use a web page, YouTube channel, public API document, or a research topic.

2

Pick AI and schedule

Select your connected AI tool or Ollama model, then choose when the task should run.

3

Deliver the result

Send the summary to Telegram or Notion, append it to an existing NotebookLM notebook, or save local TXT, HTML, and DOCX files.

4

Reply when needed

Use Telegram follow-up replies for pipeline notifications when the workflow is configured.

작동 방식

Requirements

System

  • Windows 10/11 64-bit
  • Internet connection required
  • 4 GB RAM or more

AI Features

  • External AI provider account required for Claude, Antigravity (Gemini), or Codex
  • Local CLI sign-in or service connection required
  • Ollama is optional: install Ollama, start it, and download a local model before selecting it

Telegram Bot

  • Telegram account required
  • Bot token required (create via BotFather)

시스템 요구사항

시스템

  • Windows 10/11 64-bit
  • 인터넷 연결 필수

AI 기능
