Turn repeated web checks into daily AI briefings.

TaskPilotSignal runs on your Windows PC, summarizes websites, YouTube, and API docs with your AI tools, then delivers results to Telegram, Notion, Google Docs, or Google Sheets.

Create recurring research tasks without running a separate server.
Use your own Claude, Antigravity (Gemini), Codex, or Ollama setup.
Start with practical workflows such as competitor monitoring, YouTube summaries, and weekly reports.

Getting Started Guide

The most important setup paths are pipeline creation, Google Workspace connection, and Telegram bot token verification.

1. Create a Pipeline Task

Click any screenshot to open it full size.

Screenshots hide account names, project IDs, and local file names. Use your own values on your PC.

  1. Click Add New Feature / Task from the dashboard.
  2. Choose Pipeline Task.
  3. Use AI Auto-Configure for a guided setup, or switch to manual setup.
  4. Select an AI agent and model, add a web or YouTube source, choose a delivery target, and set a schedule time.
  5. Save the task. Use Start for scheduled runs or Run Now for a manual test.

2. Connect Google Workspace

Click any screenshot to open it full size.

  1. Open Settings and click Connect Google. You only need this when a pipeline sends results to Google Docs or Sheets.
  2. Keep the TaskPilotSignal setup window open and follow only the current step. The app opens the Google page that is needed for that step.
  3. Use your own Google account and Google Cloud project. This keeps Workspace delivery under your account, quota, and permissions.
  4. If a Google page opens one menu away from the expected screen, use APIs & Services, then find OAuth consent screen or Credentials.
  5. When creating credentials, choose OAuth client ID and Desktop app, then use Google's Download JSON button.
  6. Select that Desktop app JSON in TaskPilotSignal. You do not need to copy Client ID or Secret values manually.
  7. Approve Google access in the browser, return to TaskPilotSignal, then click Check Connection or use Run Now on a pipeline to test delivery.

If Google blocks approval, add the same Google account under Test users and retry. If approval works normally, you can skip the Test users step.

3. Get a Telegram Bot Token

Click any screenshot to open it full size.

  1. Open Settings > Telegram Bot Tokens in TaskPilotSignal when you are ready to add the token. Token creation is done in Telegram, then saved here.
  2. Open Telegram and search for @BotFather. Use the official BotFather account, then send /newbot.
  3. When BotFather asks for a name, type the name users should see for your bot. When it asks for a username, type a unique value ending in bot, such as your_bot_name_bot. Do not copy the screenshot example exactly.
  4. Copy the token BotFather gives you. Treat it like a password and do not share it.
  5. Open a 1:1 chat with your new bot and send /start or any message once.
  6. Return to Settings > Telegram Bot Tokens, add the token, and click verify. Chat ID is detected automatically from your latest bot message.
  7. If verification says no chat was found, send one more message to the bot in Telegram and verify again.

Optional: Use Ollama Local AI

  1. Install Ollama separately from https://ollama.com/download.
  2. Start the Ollama app, then download at least one local model such as llama3.2.
  3. Open TaskPilotSignal Settings and select Ollama after the app detects a local model.
  4. If Ollama is not available, check that the app is running, a model is downloaded, and the host is local to this PC.

Telegram Bot Commands

  • /help - show available commands.
  • /ping - check whether the bot is alive.
  • /change ai gemini - switch the active AI provider.
  • /newsession - start a fresh AI conversation.
  • /resume - continue the saved session where available.

시작 가이드

가장 중요한 설정은 작업 파이프라인 생성, Google Workspace 연결, 텔레그램 봇 토큰 검증입니다.

1. 작업 파이프라인 만들기

스크린샷을 누르면 원본 크기로 볼 수 있습니다.

스크린샷의 계정 이름, 프로젝트 ID, 로컬 파일 이름은 가려져 있습니다. 실제 설정에서는 본인 PC의 값을 사용하세요.

  1. 대시보드에서 새로운 기능/작업 추가를 누릅니다.
  2. 파이프라인 작업을 선택합니다.
  3. 처음에는 AI 자동 설정으로 안내를 받거나, 직접 구성하려면 수동 설정으로 전환합니다.
  4. AI 에이전트와 모델, 웹 또는 YouTube 소스, 전달 대상, 실행 시간을 설정합니다.
  5. 작업을 저장한 뒤 시작으로 예약 실행하거나 즉시 실행으로 테스트합니다.

2. Google Workspace 연결

스크린샷을 누르면 원본 크기로 볼 수 있습니다.

  1. 설정에서 Google 연결을 누릅니다. 파이프라인 결과를 Google Docs나 Sheets로 보낼 때만 필요합니다.
  2. TaskPilotSignal 설정 창을 열어둔 채 현재 단계만 따라갑니다. 앱이 해당 단계에 필요한 Google 페이지를 열어줍니다.
  3. 사용자 본인의 Google 계정과 Google Cloud 프로젝트를 사용합니다. 이렇게 하면 전송 권한과 사용량이 사용자 계정/프로젝트 기준으로 관리됩니다.
  4. Google 페이지가 예상 화면보다 한 메뉴 앞뒤로 열리면 API 및 서비스에서 OAuth 동의 화면 또는 사용자 인증 정보를 찾으세요.
  5. 사용자 인증 정보를 만들 때는 OAuth 클라이언트 ID와 Desktop app을 선택한 뒤 Google의 Download JSON 버튼으로 파일을 받습니다.
  6. 다운로드한 Desktop app JSON을 TaskPilotSignal에서 선택합니다. Client ID나 Secret 값을 직접 복사해 붙여넣을 필요는 없습니다.
  7. 브라우저에서 Google 접근을 승인한 뒤 TaskPilotSignal로 돌아와 연결 확인 또는 파이프라인의 즉시 실행으로 실제 전송을 테스트합니다.

Google이 승인을 차단할 때만 같은 Google 계정을 테스트 사용자에 추가하고 다시 시도하세요. 승인 화면이 정상으로 열리면 테스트 사용자 단계는 건너뛰어도 됩니다.

3. 텔레그램 봇 토큰 얻기

스크린샷을 누르면 원본 크기로 볼 수 있습니다.

  1. TaskPilotSignal에서 설정 > 텔레그램 봇 토큰을 열어둡니다. 토큰은 Telegram에서 만든 뒤 이 화면에 저장합니다.
  2. Telegram에서 @BotFather를 검색합니다. 공식 BotFather 계정을 사용하고 /newbot을 보냅니다.
  3. BotFather가 이름을 물으면 사용자가 볼 봇 표시 이름을 입력하세요. 사용자 이름을 물으면 your_bot_name_bot처럼 bot으로 끝나는 고유한 값을 입력하세요. 스크린샷 예시를 그대로 복사하지 마세요.
  4. BotFather가 알려주는 토큰을 복사합니다. 토큰은 비밀번호처럼 다루고 다른 사람에게 공유하지 마세요.
  5. 새 봇과 1:1 채팅을 열고 /start 또는 아무 메시지를 한 번 보냅니다.
  6. 다시 설정 > 텔레그램 봇 토큰으로 돌아와 토큰을 추가하고 검증을 누릅니다. 채팅 ID는 최근 봇 메시지에서 자동 감지됩니다.
  7. 검증 시 채팅을 찾지 못했다고 나오면 Telegram에서 봇에게 메시지를 한 번 더 보내고 다시 검증하세요.

선택 기능: Ollama 로컬 AI 사용

  1. https://ollama.com/download에서 Ollama를 별도로 설치합니다.
  2. Ollama 앱을 실행하고 llama3.2 같은 로컬 모델을 하나 이상 다운로드합니다.
  3. TaskPilotSignal 설정에서 로컬 모델이 감지된 뒤 Ollama를 선택합니다.
  4. Ollama가 보이지 않으면 앱이 실행 중인지, 모델이 다운로드되어 있는지, host가 이 PC의 로컬 주소인지 확인하세요.

텔레그램 봇 명령어

  • /help - 사용할 수 있는 명령어를 확인합니다.
  • /ping - 봇이 정상 작동 중인지 확인합니다.
  • /change ai gemini - 사용할 AI 제공자를 변경합니다.
  • /newsession - 새 AI 대화를 시작합니다.
  • /resume - 가능한 경우 저장된 세션을 이어갑니다.
