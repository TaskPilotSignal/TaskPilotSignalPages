Roadmap

TaskPilotSignal launched on Microsoft Store on May 13, 2026. Version 1.1.0.0 is the current Store baseline, with first-use task suggestions, proposal-style pipeline setup, Telegram follow-up replies, and tighter VMware release QA coverage.

Open on Microsoft Store

TaskPilotSignal은 2026년 5월 13일 Microsoft Store에 출시되었습니다. 1.1.0.0은 현재 Store 기준 버전이며, 첫 사용 작업 추천, 제안형 파이프라인 설정, Telegram 후속 답장, VMware 릴리스 QA 범위를 개선했습니다.

Microsoft Store에서 열기

Current Store Baseline — 1.1.0.0

Improve First-use Task Suggestions

The add-task flow now offers clearer starting examples for briefing, monitoring, YouTube, Docs, and report workflows without overwhelming the first screen.

Improve Proposal-style Pipeline Setup

Automatic setup can now propose sensible defaults, ask for only missing required values, and keep the answer format consistent across providers and models.

Improve Telegram Follow-up Replies

Pipeline notifications include clearer reply actions so users can continue a conversation from the Telegram message that produced the result.

Continue Store-installed VMware QA

Release checks continue to use the installed app in VMware for GUI, pipeline, Telegram, provider, and package behavior before Store upload decisions.

Next Follow-up — Post 1.1

Improve First-use Templates

Turn the best starter examples into reusable templates for competitor monitoring, stock or API monitoring, YouTube summaries, recurring research briefings, and Notion or Google Sheets reports.

Improve Google Setup Simplicity

Continue reducing the number of Google Workspace decisions a non-technical user must understand before connecting Docs or Sheets.

Improve Marketing Examples

Prepare clearer examples for the first paid workflows: daily competitor checks, YouTube briefing, API or stock monitoring, and delivery to Telegram or Google Workspace.

Later Telegram-driven Pipeline Creation

Pipeline creation from bot chat remains a later feature after the Workspace context model and duplicate-response guard stay stable.

Improve Store-installed QA Automation

Keep tightening VMware Store-like QA, Telegram Desktop button checks, provider/model sampling, and screenshot-based GUI clipping checks.

Recent Platform Update

Release Microsoft Store Launch

TaskPilotSignal launched on Microsoft Store on May 13, 2026. The first release focuses on pipeline automation, Telegram bot setup, and local-first account connections.

현재 Store 기준 버전 — 1.1.0.0

Improve 첫 사용 작업 추천

처음 작업을 추가할 때 브리핑, 모니터링, YouTube, Docs, 보고서 흐름을 과도한 정보 없이 시작 예시로 확인할 수 있습니다.

Improve 제안형 파이프라인 설정

자동 설정이 기본값을 먼저 제안하고, 꼭 필요한 누락값만 물어보며, 제공자와 모델이 달라도 답변 형식을 일관되게 유지합니다.

Improve Telegram 후속 답장

파이프라인 알림에 더 명확한 답장 액션을 포함해 결과가 온 Telegram 메시지에서 대화를 이어가기 쉽게 했습니다.

Continue Store 설치 기준 VMware QA

Store 업로드 판단 전 VMware에 설치된 앱 기준으로 GUI, 파이프라인, Telegram, 제공자, 패키지 동작을 계속 확인합니다.

다음 후속 작업 — 1.1 이후

Improve 첫 사용 템플릿

경쟁사 모니터링, 주식 또는 API 모니터링, YouTube 요약, 정기 리서치 브리핑, Notion 또는 Google Sheets 보고 예시를 재사용 가능한 템플릿으로 발전시킵니다.

Improve Google 설정 단순화

비개발자가 Google Docs 또는 Sheets 연결 전에 이해해야 하는 선택지를 더 줄이고, 필요한 단계만 더 쉽게 안내합니다.

Improve 홍보 예시 정리

일일 경쟁사 확인, YouTube 브리핑, API 또는 주식 모니터링, Telegram 또는 Google Workspace 전송처럼 첫 유료 사용자가 바로 이해할 예시를 정리합니다.

Later 텔레그램에서 파이프라인 만들기

봇 대화로 파이프라인을 새로 만드는 기능은 Workspace 문맥 모델과 중복 응답 방지가 안정된 뒤 이후 기능으로 둡니다.

Improve Store 설치 기준 QA 자동화

VMware Store-like QA, Telegram Desktop 버튼 테스트, 제공자/모델 샘플링, 스크린샷 기반 GUI 잘림 검사를 계속 강화합니다.
