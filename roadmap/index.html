Roadmap

TaskPilotSignal launched on Microsoft Store on May 13, 2026. Version 1.0.6.0 is planned as a stabilization update before the next larger feature cycle.

Open on Microsoft Store

TaskPilotSignal은 2026년 5월 13일 Microsoft Store에 출시되었습니다. 1.0.6.0은 다음 큰 기능 업데이트 전 안정화 업데이트로 준비 중입니다.

Microsoft Store에서 열기

Next Update — 1.0.6.0 Stabilization

Improve Store Install Reliability

Keep packaged runtime behavior conservative so provider CLI setup works from Microsoft Store installs and app-managed folders.

Improve Telegram Bot Setup Guidance

Make BotFather token creation, token verification, and first bot message setup easier to follow with clearer app and web guidance.

Improve Pipeline Auto-Configuration

Let users describe tasks naturally, preserve setup context across provider/model changes, and ask only for missing details.

Improve Safer Failure Messages

Continue reducing raw diagnostic exposure while making incomplete setup states easier for users to understand.

Improve Regression Coverage

Expand checks around Telegram bot permissions, pipeline setup, and Store-like packaged execution.

Planned Improvements

New Ollama Local AI Support in 1.0.7.0

Add a local AI option for users who want to run supported models on their own PC.

New Continue Pipeline Results in Telegram

Send scheduled pipeline results to Telegram and continue the conversation with the Telegram AI bot using the pipeline result as context.

Improve AI Usage Visibility

Show task-level token usage, provider limit status, and documented plan reference limits for Telegram bots and pipeline runs.

Recent Platform Update

Release Microsoft Store Launch

TaskPilotSignal launched on Microsoft Store on May 13, 2026. The first release focuses on pipeline automation, Telegram bot setup, and local-first account connections.

다음 업데이트 — 1.0.6.0 안정화

Improve Store 설치 안정성

Microsoft Store 설치와 앱 관리 폴더 기준에서 제공자 CLI 설정이 안정적으로 동작하도록 런타임 흐름을 보수적으로 유지합니다.

Improve 텔레그램 봇 설정 안내

BotFather 토큰 생성, 토큰 검증, 첫 봇 메시지 설정을 앱과 웹 가이드에서 더 쉽게 따라갈 수 있게 합니다.

Improve 파이프라인 자동 설정

사용자가 자연스럽게 말해도 작업을 이해하고, AI 에이전트나 모델을 바꿔도 설정 중인 내용을 이어가도록 개선합니다.

Improve 더 안전한 오류 메시지

원시 진단 정보 노출을 줄이면서도 설정이 왜 완료되지 않았는지 사용자가 바로 이해할 수 있게 합니다.

Improve 회귀 테스트 보강

텔레그램 봇 권한, 파이프라인 설정, Store-like 패키지 실행 기준 검증을 더 보강합니다.

예정된 개선 사항

New 1.0.7.0 Ollama 로컬 AI 지원

지원되는 모델을 사용자 PC에서 직접 실행하고 싶은 사용자를 위한 로컬 AI 옵션을 추가할 예정입니다.

New 파이프라인 결과를 텔레그램 대화로 이어가기

예약 파이프라인 결과를 텔레그램으로 받은 뒤, 해당 결과를 문맥으로 삼아 텔레그램 AI 봇과 이어서 대화할 수 있게 합니다.

Improve AI 사용량 표시

텔레그램 봇과 파이프라인 실행별 토큰 사용량, 제공자 제한 상태, 요금제별 공식 참고 한도를 함께 확인할 수 있게 합니다.
