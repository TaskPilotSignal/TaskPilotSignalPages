Roadmap

Microsoft Store launch is planned for May 2026. The next feature update is planned within June 2026.

2026년 5월 Microsoft Store 출시를 목표로 하며, 다음 기능 업데이트는 2026년 6월 내 진행 예정입니다.

Next Update — Within June 2026

Release Microsoft Store Launch

TaskPilotSignal is being prepared for Microsoft Store release in May 2026. The first release focuses on pipeline automation, Telegram bot setup, and local-first account connections.

New Multi-Step Pipeline Tasks

Create more complex pipelines that combine multiple sources, analysis steps, and delivery targets in one task.

New Edit Pipelines via Telegram Bot

Modify pipeline task settings directly from your Telegram AI bot. No need to open the desktop app for quick adjustments.

New Telegram Bot Session ID Display

See the active AI session ID in Telegram so conversations can be identified and resumed more reliably.

Improve Task Instructions for AI Agents

Add per-bot and per-pipeline instructions that sync to provider-specific files such as AGENTS.md, CLAUDE.md, and GEMINI.md inside each task workspace.

Improve AI Usage Visibility

Show task-level token usage, provider limit status, and documented plan reference limits for Telegram bots and pipeline runs.

Planned Improvements

New Continue Pipeline Results in Telegram

Send scheduled pipeline results to Telegram and continue the conversation with the Telegram AI bot using the pipeline result as context.

Improve AI Effort Controls

Add effort controls for supported AI agents such as Codex and Claude while keeping unsupported providers simple.

Improve Smaller Installer Strategy

Review bundled runtime size and move large optional tools toward on-demand setup where it does not hurt first-run reliability.

Recent Platform Update

다음 업데이트 — 2026년 6월 내

Release Microsoft Store 출시

TaskPilotSignal은 2026년 5월 Microsoft Store 출시를 준비 중입니다. 첫 출시는 파이프라인 자동화, 텔레그램 봇 설정, 로컬 중심 계정 연결에 집중합니다.

New 복합 작업 파이프라인

여러 소스, 분석 단계, 전달 대상을 하나의 작업으로 묶는 더 복잡한 파이프라인을 만들 수 있게 됩니다.

New 텔레그램 봇으로 파이프라인 수정

텔레그램 AI 봇에서 직접 파이프라인 작업 설정을 수정합니다. 간단한 변경은 데스크톱 앱을 열 필요 없습니다.

New 텔레그램 봇 세션 ID 표시

텔레그램에서 현재 AI 세션 ID를 확인해 대화를 더 안정적으로 구분하고 이어갈 수 있게 됩니다.

Improve AI 에이전트별 작업 지침

봇과 파이프라인별 지침을 입력하면 각 작업 루트 안의 AGENTS.md, CLAUDE.md, GEMINI.md 같은 제공자별 지침 파일로 동기화되도록 개선합니다.

Improve AI 사용량 표시

텔레그램 봇과 파이프라인 실행별 토큰 사용량, 제공자 제한 상태, 요금제별 공식 참고 한도를 함께 확인할 수 있게 합니다.

예정된 개선 사항

New 파이프라인 결과를 텔레그램 대화로 이어가기

예약 파이프라인 결과를 텔레그램으로 받은 뒤, 해당 결과를 문맥으로 삼아 텔레그램 AI 봇과 이어서 대화할 수 있게 합니다.

Improve AI effort 설정

Codex와 Claude처럼 지원되는 AI 에이전트에는 effort 설정을 추가하고, 지원하지 않는 제공자는 단순한 모델 선택 흐름을 유지합니다.

Improve 설치 용량 최적화

번들 런타임 크기를 점검하고, 첫 실행 안정성을 해치지 않는 범위에서 큰 선택 도구를 필요 시 설치 방식으로 전환하는 방안을 검토합니다.
