Roadmap

TaskPilotSignal launched on Microsoft Store on May 13, 2026. Version 1.0.9.0 is the current Store baseline, with clearer Google Workspace setup, improved non-developer guidance, and tighter Telegram and pipeline reliability.

Open on Microsoft Store

TaskPilotSignal은 2026년 5월 13일 Microsoft Store에 출시되었습니다. 1.0.9.0은 현재 Store 기준 버전이며, Google Workspace 설정 안내, 비개발자용 설명, Telegram 알림과 파이프라인 안정성을 개선했습니다.

Microsoft Store에서 열기

Current Store Baseline — 1.0.9.0

Improve Easier Google Workspace Setup

The Google Workspace guide now explains project ID, Desktop app JSON, browser approval, connection checks, and when Test users are needed.

Improve Clearer Non-Developer Setup Copy

Task creation, settings, and optional service connections use simpler wording so users can understand what is required before running a workflow.

Improve Telegram and Pipeline Reliability

Telegram notification, pipeline setup, and connection-readiness flows were tightened to reduce confusing setup and delivery states.

Continue Local AI and Provider Options

Claude, Antigravity (Gemini), Codex, and optional Ollama support remain available through user-owned provider accounts or local setup.

Next Follow-up — Post 1.0.9

Improve First-use Templates

Add clearer starting templates for competitor monitoring, stock or API monitoring, YouTube summaries, recurring research briefings, and Notion or Google Sheets reports.

Improve Usage and Failure Explanations

Show clearer reasons when a setup, provider run, delivery target, or workflow remains incomplete, with the next action visible in the app.

Improve Telegram Reply Experience

Improve how users reply to pipeline results from Telegram while keeping bot chat, notification replies, and pipeline context separated.

Later Telegram-driven Pipeline Creation

Pipeline creation from bot chat remains a later feature after the Workspace context model and duplicate-response guard stay stable.

Improve Store-installed QA Automation

Keep tightening VMware Store-like QA, Telegram Desktop button checks, provider/model sampling, and screenshot-based GUI clipping checks.

Recent Platform Update

Release Microsoft Store Launch

TaskPilotSignal launched on Microsoft Store on May 13, 2026. The first release focuses on pipeline automation, Telegram bot setup, and local-first account connections.

현재 Store 기준 버전 — 1.0.9.0

Improve Google Workspace 설정 안내 개선

프로젝트 ID, Desktop app JSON, 브라우저 승인, 연결 확인, Test users가 필요한 경우를 단계별로 더 쉽게 설명합니다.

Improve 비개발자용 설정 문구 개선

작업 추가, 설정, 선택 서비스 연결 화면에서 실행 전에 무엇이 필요한지 더 쉽게 이해할 수 있도록 문구를 정리했습니다.

Improve Telegram 알림과 파이프라인 안정성

Telegram 알림, 파이프라인 설정, 연결 준비 상태 흐름을 다듬어 설정과 전송 상태가 더 명확하게 보이도록 개선했습니다.

Continue 로컬 AI와 제공자 선택 유지

Claude, Antigravity(Gemini), Codex, 선택형 Ollama는 사용자 소유 계정 또는 로컬 설정 기준으로 계속 사용할 수 있습니다.

다음 후속 작업 — 1.0.9 이후

Improve 첫 사용 템플릿

경쟁사 모니터링, 주식 또는 API 모니터링, YouTube 요약, 정기 리서치 브리핑, Notion 또는 Google Sheets 보고용 시작 템플릿을 더 명확하게 추가합니다.

Improve 사용량과 실패 이유 설명

설정, 제공자 실행, 전송 대상, 워크플로우가 미완료 상태일 때 이유와 다음 조치를 앱 안에서 더 명확하게 보여줍니다.

Improve Telegram 답장 경험

파이프라인 결과에 Telegram에서 답장할 때 일반 봇 대화, 알림 답장, 파이프라인 문맥이 섞이지 않도록 더 명확하게 개선합니다.

Later 텔레그램에서 파이프라인 만들기

봇 대화로 파이프라인을 새로 만드는 기능은 Workspace 문맥 모델과 중복 응답 방지가 안정된 뒤 이후 기능으로 둡니다.

Improve Store 설치 기준 QA 자동화

VMware Store-like QA, Telegram Desktop 버튼 테스트, 제공자/모델 샘플링, 스크린샷 기반 GUI 잘림 검사를 계속 강화합니다.
