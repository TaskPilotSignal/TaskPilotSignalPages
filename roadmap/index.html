Roadmap

TaskPilotSignal launched on Microsoft Store on May 13, 2026. Version 1.0.7.0 is the current Store baseline, and 1.0.8.0 is focused on stabilization and package optimization.

Open on Microsoft Store

TaskPilotSignal은 2026년 5월 13일 Microsoft Store에 출시되었습니다. 1.0.7.0은 현재 Store 기준 버전이고, 1.0.8.0은 안정화와 패키지 최적화에 집중합니다.

Microsoft Store에서 열기

Current Store Baseline — 1.0.7.0

New Ollama Local AI Support

Use an optional local AI provider after installing Ollama, starting the app, and downloading at least one local model. TaskPilotSignal uses local Ollama access only.

Improve Consistent AI Execution

Pipeline runs, pipeline auto-configuration, and Telegram bot replies now use more consistent AI execution behavior while keeping each task root separate.

Improve Clearer Incomplete-State Reasons

Setup and run screens show safer, user-friendly reasons when something is incomplete instead of exposing raw diagnostic output.

Improve Google and Notion Delivery Checks

Connection status, delivery readiness, and run evidence are clearer for Google Docs, Google Sheets, Notion, and Telegram delivery flows.

Improve Store-like QA Coverage

Validation around packaged installs, AI provider setup, pipeline setup, Telegram bot behavior, and Ollama runtime was expanded.

Next Stabilization — 1.0.8.0

Improve Package Size Optimization

Reduce bundled runtime size while keeping Store-installed AI setup, Google Workspace delivery, and local runtime behavior reliable.

Improve Stability and Refactoring

Continue simplifying release QA helpers, provider setup paths, and app-managed runtime checks before the next feature cycle.

New Telegram Bot File Handling

Planned work covers safe file receive/send flows for Telegram bot tasks, including file size, path, and execution safeguards.

New Continue Pipeline Results in Telegram

Send scheduled pipeline results to Telegram and continue the conversation with the Telegram AI bot using the pipeline result as context.

Improve AI Usage Visibility

Show task-level token usage, provider limit status, and documented plan reference limits for Telegram bots and pipeline runs.

Recent Platform Update

Release Microsoft Store Launch

TaskPilotSignal launched on Microsoft Store on May 13, 2026. The first release focuses on pipeline automation, Telegram bot setup, and local-first account connections.

현재 Store 기준 버전 — 1.0.7.0

New Ollama 로컬 AI 지원

Ollama를 설치하고 앱을 실행한 뒤 로컬 모델을 다운로드한 사용자가 선택할 수 있는 로컬 AI 제공자를 포함합니다. TaskPilotSignal은 로컬 Ollama 접근만 사용합니다.

Improve 일관된 AI 실행

각 작업 폴더는 분리된 상태로 유지하면서 파이프라인 실행, 자동 설정, 텔레그램 봇 답변의 AI 실행 방식을 더 일관되게 정리했습니다.

Improve 미완료 상태 이유 표시

설정이나 실행이 완료되지 않았을 때 원시 진단 정보 대신 사용자가 이해하기 쉬운 이유를 보여줍니다.

Improve Google과 Notion 전송 확인

Google Docs, Google Sheets, Notion, Telegram 전송 흐름에서 연결 상태, 전송 준비 상태, 실행 결과 확인을 더 명확하게 했습니다.

Improve Store-like QA 보강

패키지 설치, AI 제공자 설정, 파이프라인 설정, 텔레그램 봇 동작, Ollama 런타임 기준 검증을 보강했습니다.

다음 안정화 — 1.0.8.0

Improve 패키지 크기 최적화

Store 설치 기준 AI 설정, Google Workspace 전송, 로컬 런타임 안정성을 유지하면서 포함 런타임 크기를 줄입니다.

Improve 안정화와 리팩토링

다음 기능 개발 전에 release QA 도구, 제공자 설정 흐름, 앱 관리 런타임 확인 로직을 계속 단순화합니다.

New 텔레그램 봇 파일 처리

파일 크기, 경로, 실행 안전장치를 포함한 텔레그램 봇 파일 수신/전송 흐름을 준비합니다.

New 파이프라인 결과를 텔레그램 대화로 이어가기

예약 파이프라인 결과를 텔레그램으로 받은 뒤, 해당 결과를 문맥으로 삼아 텔레그램 AI 봇과 이어서 대화할 수 있게 합니다.

Improve AI 사용량 표시

텔레그램 봇과 파이프라인 실행별 토큰 사용량, 제공자 제한 상태, 요금제별 공식 참고 한도를 함께 확인할 수 있게 합니다.
