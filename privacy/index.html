Privacy Policy

1. Information We Process

TaskPilotSignal processes information that users directly provide or generate while using the app, including:

  • Telegram bot tokens
  • Telegram, Notion, NotebookLM notebook binding, or other service connection data that the user chooses to configure
  • Task definitions, app settings, and bot/session metadata required for local operation
  • Local sign-in or session data owned by third-party CLI tools that the user chooses to use; TaskPilotSignal does not copy those provider session files into its package or managed configuration
  • TXT, HTML, or DOCX output that the user chooses to create in the app-owned local workspace

Sensitive local settings are stored on the user's PC. On Windows, supported secret fields are protected with Windows DPAPI.

2. External Transmission

TaskPilotSignal sends data only to the external services that the user chooses to connect:

  • AI providers or AI CLI tools chosen by the user — prompt/response processing
  • Telegram API — bot message communication
  • Notion API — page delivery selected by the user
  • NotebookLM Personal — visible default-browser interaction with an existing notebook selected by the user
  • YouTube and web sources — user-requested content access

We do not operate our own relay or storage server for this app. TaskPilotSignal does not send your data to a separate developer-run backend.

Local TXT, HTML, and DOCX delivery stays on the user's PC unless the user later shares those files. NotebookLM Personal does not copy or store browser cookies, browser profiles, session tokens, or notebook page contents.

3. Telegram Data

The app communicates with the Telegram API using the user's own bot token. Raw transcript persistence is off by default, but limited local session/state metadata may be stored privately so the bot can operate and resume safely.

4. Local Storage

Release builds store settings, logs, session/state files, and local document output in app-specific per-user storage under LocalAppData or package LocalState/LocalCache, not in the WindowsApps installation directory.

These local files may include diagnostics, queue/session state, configuration data, saved notebook binding, and user-requested local documents needed for the selected workflow.

5. Third-Party Services

Each AI provider and external service has its own privacy policy:

  • Anthropic: anthropic.com/legal/privacy
  • OpenAI: openai.com/policies/privacy-policy
  • Google: policies.google.com/privacy
  • Notion: notion.com/trust/privacy-policy
  • Telegram: telegram.org/privacy

6. Data Deletion

Uninstalling the app may not automatically remove every per-user file. Before removal, users can open the app-owned workspace with Open Folder and delete exported documents they no longer need. For help locating other local app data, use Status & Help or contact support.

개인정보처리방침

1. 처리하는 정보

TaskPilotSignal은 사용자가 직접 입력하거나 사용 중에 생성되는 다음 정보를 처리합니다:

  • 텔레그램 봇 토큰
  • 사용자가 설정한 Telegram, Notion, NotebookLM 노트북 연결 정보 등 외부 서비스 연결 정보
  • 작업 정의, 앱 설정, 봇/세션 운영에 필요한 메타데이터
  • 사용자가 선택한 외부 CLI 도구가 소유하는 로컬 로그인 또는 세션 정보. TaskPilotSignal은 해당 공급자 세션 파일을 패키지나 앱 관리 설정으로 복사하지 않습니다.
  • 사용자가 앱 전용 로컬 작업공간에 만들도록 선택한 TXT, HTML, DOCX 결과물

민감한 로컬 설정값은 사용자 PC에 저장되며, Windows에서는 지원되는 항목이 Windows DPAPI로 보호됩니다.

2. 외부 전송

사용자가 설정한 외부 서비스에만 요청을 전송합니다:

  • 사용자가 선택한 AI 제공자 또는 AI CLI 도구 — 프롬프트/응답 처리
  • Telegram API — 봇 메시지 송수신
  • Notion API — 사용자가 선택한 페이지로 결과 전달
  • NotebookLM Personal — 사용자가 선택한 기존 노트북과 보이는 기본 브라우저에서 상호작용
  • YouTube 및 웹 소스 — 사용자가 요청한 콘텐츠 접근

별도의 개발자 운영 중계/저장 서버로 데이터를 보내지 않습니다. TaskPilotSignal은 이 앱을 위한 별도 백엔드를 운영하지 않습니다.

로컬 TXT, HTML, DOCX 전달은 사용자가 나중에 해당 파일을 공유하지 않는 한 PC 안에 남습니다. NotebookLM Personal 기능은 브라우저 쿠키, 브라우저 프로필, 세션 토큰 또는 노트북 페이지 내용을 복사하거나 저장하지 않습니다.

3. 텔레그램 데이터

사용자의 텔레그램 봇 토큰을 사용하여 Telegram API와 통신합니다. 원문 대화 저장은 기본적으로 꺼져 있지만, 봇의 안정적 동작과 세션 복구를 위해 제한적인 로컬 상태/메타데이터가 비공개 저장소에 기록될 수 있습니다.

4. 로컬 저장

릴리스 빌드는 설정, 로그, 세션/상태 파일, 로컬 문서 결과물을 WindowsApps 설치 폴더가 아니라 LocalAppData 또는 패키지 LocalState/LocalCache 아래의 앱 전용 사용자별 저장소에 기록합니다.

이 로컬 파일에는 진단 로그, 큐/세션 상태, 설정 데이터, 저장한 노트북 연결 정보, 사용자가 요청한 로컬 문서가 포함될 수 있습니다.

5. 제3자 서비스

각 AI 제공자 및 외부 서비스의 개인정보 처리방침은 해당 서비스의 약관에 따릅니다:

  • Anthropic: anthropic.com/legal/privacy
  • OpenAI: openai.com/policies/privacy-policy
  • Google: policies.google.com/privacy
  • Notion: notion.com/trust/privacy-policy
  • Telegram: telegram.org/privacy

6. 데이터 삭제

앱 제거만으로 모든 사용자별 파일이 자동 삭제되지 않을 수 있습니다. 제거 전에 폴더 열기로 앱 전용 작업공간을 열고 필요 없는 내보낸 문서를 삭제할 수 있습니다. 다른 로컬 앱 데이터 위치는 상태/도움말 또는 고객지원을 통해 확인하세요.
